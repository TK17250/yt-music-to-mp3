# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Instead, report them privately via
[GitHub Security Advisories](https://github.com/TK17250/yt-music-to-mp3/security/advisories/new).
You should receive a response within a few days.

Note: never share your `cookies.txt` or browser cookies in issues. They grant access to your
YouTube/Google account.
